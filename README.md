# SparkHome

A tvOS-style home screen for the NVIDIA DGX Spark: streaming apps, Steam games and a voice assistant on the TV,
driven by an Apple Siri Remote, a gamepad, a phone or your voice.

**Release guide:** https://a-funk.github.io/sparkhome/ covers what it does, with videos, stills and how each part works.

The guide is published from the `gh-pages` branch. SparkHome's source isn't published here yet.

Related, and public:
- [open-appleremote](https://github.com/a-funk/open-appleremote): the gen-1 Siri Remote on Linux, from SparkHome's remote support.
- [GameSpark](https://github.com/a-funk/GameSpark): makes Steam games run better on the DGX Spark.
