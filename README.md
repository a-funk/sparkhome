# SparkHome release guide

A one-page guide to the October 2026 release of SparkHome, a TV launcher for the NVIDIA DGX Spark: what changed, how to try each piece from the couch, and what's next.

Live at https://a-funk.github.io/sparkhome/

This is the public edition of a private release guide, and it is generated from that guide. Account and sign-in details, machine-specific names and paths, and personal to-dos are left out. A few screenshots and video frames are blurred for the same reason.

The site is static. `index.html` holds the whole page with its CSS inline, and `media/` holds the stills, three silent demo videos and the link-preview image. Fonts come from Google Fonts, and mermaid, loaded from jsDelivr, draws the diagrams. `.nojekyll` tells GitHub Pages to serve the files as they are.
